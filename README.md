# Terraria — Site em HTML

Projeto acadêmico desenvolvido para a disciplina de **HTML Avançado**, com o objetivo de criar um site informativo sobre o jogo **Terraria**, utilizando exclusivamente recursos do HTML.

O projeto foi desenvolvido sem o uso de CSS ou JavaScript, utilizando os próprios recursos estruturais, semânticos e interativos do HTML5.

---

## 🎮 Sobre o projeto

O site apresenta diferentes informações sobre Terraria, organizadas em várias páginas HTML.

Entre os conteúdos apresentados estão:

- Informações gerais sobre Terraria;
- Personagens e classes;
- Biomas;
- Chefes;
- Itens, armas e armaduras;
- NPCs;
- Eventos;
- Progressão do jogo;
- Gameplay.

O projeto também utiliza elementos de multimídia, formulários, elementos semânticos e recursos avançados do HTML.

---

## 📄 Páginas

O site possui **11 páginas HTML**, conectadas por meio de um menu de navegação presente nas páginas.

| Página | Descrição |
|---|---|
| `index.html` | Página inicial e apresentação do site |
| `sobre.html` | Informações gerais e curiosidades sobre Terraria |
| `personagens.html` | Personagem do jogador, classes e personalização |
| `biomas.html` | Principais biomas encontrados no jogo |
| `chefes.html` | Chefes de Pré-Hardmode e Hardmode |
| `itens.html` | armas e armaduras finais das classes |
| `npcs.html` | Informações sobre NPCs e suas condições |
| `eventos.html` | Eventos de Pré-Hardmode e Hardmode |
| `progressao.html` | Etapas e evolução da progressão no jogo |
| `contato.html` | Formulário demonstrativo utilizando recursos avançados do HTML |
| `gameplay.html` | Vídeo de gameplay de Terraria |
